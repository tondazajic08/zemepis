# USA & Canada

Vzdělávací web k maturitě ze zeměpisu: prezentace, interaktivní mapa, rozšířené informace, kvízy a maturitní příprava.

Web je čistě statický (HTML, CSS, JavaScript), nepotřebuje žádnou instalaci a funguje i bez internetu. Stačí otevřít `index.html`.

## Zveřejnění na GitHub Pages

1. Nahraj obsah této složky do repozitáře na GitHubu.
2. V repozitáři otevři **Settings → Pages**.
3. U **Source** zvol **Deploy from a branch**, větev `main` a složku `/ (root)`.

## Ovládání prezentace

Šipky nebo mezerník posouvají slidy, `F` zapne celou obrazovku, na mobilu funguje přejetí prstem.

## Zdroje

- Mapy: [Natural Earth](https://www.naturalearthdata.com/), volné dílo.
- Fotografie: Wikimedia Commons, autor a licence jsou uvedeny u každého snímku na stránce Mapa.
